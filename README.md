基于ESP32+STM32-CAN的四足八自由度仿生机器人控制系统
成品及演示视频链接：【八自由度仿生蜘蛛】https://www.bilibili.com/video/BV1hPtP6PEDg?vd_source=17448070ebaaecc96f881a46127a8576
项目简介：基于双MCU架构在CAN通信下控制机器人的八自由度步态，实现WIFI网页/语音遥控，OTA远程管理及低功耗管理
技术栈：ESP32-S3,Arduino框架,CAN通信,SU-03T,WIFI配网,OTA远程升级,低功耗管理,看门狗Web网页,运动学与步态控制
核心工作与重难点:
1.采用CAN通信双MCU保证实时性，ESP32端作为上位机负责人机交互与通信，STM32端作为下位机专职实时运动控制。
2.在ESP32-S3端解析SU-03T语音指令(AA 55 XX 55 AA)提供语音控制,配置WIFI热点和WebServer提供网页平台控制,集成ArduinoOTA远程固件升级，并设置硬件看门狗(10秒)保证系统长期运行稳定性。
3.在STM32端利用运动学专职八自由度的步态调节,由PCA9685 I2C驱动8路PWM输出控制舵机完成各种指令动作，并加以平滑插值(20ms)消除顿挫感，且设置低功耗管理，睡眠状态下功耗仅为0.8mA。
